About NIDS

Network Intrusion Detection System v1.0

A fully functional Network Intrusion Detection System built from scratch in C++17 using libpcap for real-time packet capture and analysis.

The system captures live network packets, analyzes them against a custom rule engine, and generates severity-based alerts for suspicious activity including port scans, ping floods, and known attack signatures.
